## 🚀 Quick Start (3 Steps)

### Step 1: Add API Keys
```bash
# Edit .env file in project root
# Add at least one API key:

OPENAI_API_KEY=sk_your_key_here
# OR
OPENROUTER_API_KEY=your_key_here
# OR
GEMINI_API_KEY=your_key_here
```

### Step 2: Start Server
```bash
cd c:\xampp\htdocs\AI-email-debugger
php artisan serve
```

### Step 3: Open Browser
```
http://localhost:8000
```

Done! 🎉

## 🚨 Important Notes

### ⚠️ Security
- This is a **LOCAL UTILITY TOOL**
- Do NOT deploy to production public server
- Keep `.env` file private (don't share it)
- Use in private/local environments only

- No database storage of emails
- No user accounts
- No history tracking
- Each request is independent
- No persistent data

The code is clean and easy to customize:

## 📞 Troubleshooting Quick Guide

| Issue | Solution |
|-------|----------|
| Port 8000 in use | Use `php artisan serve --port=8001` |
| API key error | Add to `.env` and run `php artisan config:clear` |
| SMTP failed | Check credentials and port (usually 587) |
| Invalid JSON | Verify API key is valid and has credits |
| Page not loading | Check browser console for errors |

Full troubleshooting in [README.md](README.md#-troubleshooting)
